# Auto-Studio

Dépôt du projet Auto-Studio.

## État du projet

Le dépôt est initialisé. Le code de l’application et les instructions
d’installation, de démarrage et de test seront ajoutés avec le développement.

## Développement

- Branche principale : `main`.
- Ne pas versionner les secrets ni les fichiers de configuration contenant des
  identifiants. Utiliser un fichier `.env.example` sans valeurs sensibles pour
  documenter les variables nécessaires.
